# API Rate Limits

Northwind Cloud enforces API rate limits per project. The Starter tier allows 60 requests per minute, Growth allows 300 requests per minute, and Business allows 1,200 requests per minute. Usage is counted in rolling one-minute windows, and every response carries an X-RateLimit-Remaining header showing the remaining budget. When a limit is exceeded, the API returns HTTP 429 together with a Retry-After header that states how many seconds to wait. Clients should retry with exponential backoff starting at 1 second, with a maximum of 5 retries; retrying immediately without backoff can extend the throttle. Rate limits apply to all REST endpoints, and webhook deliveries are capped at 20 per minute per endpoint. Business customers can request higher limits by opening a support ticket.
